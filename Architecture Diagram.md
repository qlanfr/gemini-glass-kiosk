## Data Flow Diagram

```mermaid
sequenceDiagram
    participant U as User 👤
    participant F as Flutter App 📱
    participant B as FastAPI Backend
    participant G as Gemini 3.0 Flash

    U->>F: 키오스크에 카메라 비춤 + "이거 뭐야?"
    F->>B: Video Frame + Audio Stream
    B->>G: Multimodal Input (Image + Text)

    Note over G: 1. 이미지 분석 (메뉴, 가격)<br/>2. 손가락 좌표 감지<br/>3. 언어 감지 (ko-KR)<br/>4. Visual Grounding 검증

    G-->>B: Structured Response
    B-->>F: JSON Response

    Note over F: AR Overlay 렌더링<br/>+ TTS 음성 출력

    F-->>U: 🔊 "베이컨 토마토 디럭스예요!"<br/>📍 메뉴 하이라이트
```
